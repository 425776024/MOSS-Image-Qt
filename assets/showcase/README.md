# 演示素材

本目录为项目作者提供并指定用于 README 展示的素材。

- `text-edit-before-after.png`：中英文文字替换对比，原图原样保留。
- `portrait-edit-before-after.png`：局部发色编辑对比，原图原样保留。
- `avatar-demo-01.mp4`：多种形象的口型对比，约 84 秒。
- `avatar-demo-02.mp4`：视频人物的口型对比，约 20 秒。
- 两张 JPG 是视频第 1 秒的封面。

视频保留原始 H.264 画面与 AAC 声音，仅重封装、移除可选元数据并前置播放索引，没有重新编码。视频中的「5000 + 静音校准」表示优化版对比。

README 使用 GitHub 视频附件提供内嵌播放器。第一段在线播放副本为满足 10 MB 限制重新编码为 H.264，保留 768×720、25 fps、84 秒和原 AAC 声音；第二段直接使用本目录视频。仓库中的两段原始视频保持不变。
